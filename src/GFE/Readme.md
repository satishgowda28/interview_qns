# Frontend Spaced Repetition Tracker

## Repetition Rules

- **R1** → 1–2 days after solving
- **R2** → 7 days after R1
- **R3** → 30 days after R2

**Status**

- [ ] Not done
- [R] Smooth (≤ 5 min)
- [S] Struggled
- [W] Weak (stuck / looked at solution)

**Daily Workflow**

1. Check today's due items
2. Solve from memory
3. Update status
4. If `[W]` → add to `weak-problems.md`
